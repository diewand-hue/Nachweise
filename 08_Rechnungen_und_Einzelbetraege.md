# 08 Rechnungen und Einzelbeträge

## Registerregel

Jeder Einzelbetrag wird mit Jahr, Zeitraum, Kostenart, Ebene, Originaldatei, Seite, Betrag, Zahlungsnachweis und Beweis-ID erfasst.

## Mindestfelder

| Feld | Inhalt |
|---|---|
| Index | `BK-1-YYYY` oder `B-03-NNN` |
| Originalname | exakter Dateiname |
| Kostenart | BK/Heizung/Warmwasser/Zusatzkosten |
| Ebene | Gebäude/Wohnung/Jobcenter |
| Betrag | Originalwert und Währung |
| Zahlungsstatus | belegt/offen |
| Quelle | Datei und Seite |
| Rechenweg | Formel oder Tabellenzeile |
| Prüfstatus | bestätigt/abweichend/offen |

Doppelzählungen und unklare Komponenten werden im Forderungsregister gesondert ausgewiesen.
